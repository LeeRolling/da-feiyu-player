# 大肥鱼播放器 · Da Fei Yu Player

> 一个**单文件、零依赖**的音乐可视化播放器。
> 为一首歌写的 —— 但它对任何一首歌都好用。

打开 `index.html` 就能跑。不需要安装、不需要构建、不需要联网。

## 快速开始

1. 下载 `index.html`
2. 双击用 **Chrome / Edge** 打开
3. 点 **🎵 选音乐** 选你的 mp3
4. 点 **🖼 选封面** 选一张图
5. 点 **📝 歌词**，粘贴歌词，点 **应用歌词**

没有时间戳也能用 —— 会自动均匀分配。想准就用下面的方法。

---

## 歌词时间轴

### ① 打轴（最准）

点 **🎯 打轴** → 从头播放 → **每唱到一句，按一下空格**（或点一下画面）。
打完自动生成 LRC，自动填回歌词框。

### ② 自动对齐（最快）

点 **🎼 自动对齐** → 分析音频的音头，把 N 行歌词铺到 N 个音头峰值上。

算法：一阶差分高通（压掉鼓与低频）→ 短时能量包络 → 自适应阈值峰值检测 → **动态规划**挑选时间递增且间隔足够的 N 个峰值。

粗对齐，之后微调几下就准了。

### ③ 手动填模板

用 `samples/` 里的模板，边听边填 `mm:ss.xx`。播放器左下角有**百分秒计时**，照着抄就行。

### 微调

右侧面板的 **时间轴微调**：

- 点一行选中 → **▶ 试听** 会跳到那句前 0.35 秒开始播放
- **−0.1s / +0.1s / −0.5s / +0.5s** 按钮
- 键盘 `,` 和 `.` 是 ±0.1 秒，按住 `Shift` 是 ±0.5 秒

| 键 | 作用 |

## 录制与导出

点 **⏺ 录制视频** → 自动回到开头、自动播放、结束自动停止 → 下载视频。

浏览器支持时直接出 **MP4**；否则出 WebM，用 ffmpeg 转：

~~~bash
ffmpeg -i input.webm -c:v libx264 -crf 18 -preset slow -c:a aac -b:a 192k output.mp4
~~~

> ⚠️ 录制只抓 canvas，**界面栏不会进画面**，放心。
>
> 竖屏版：把 `W` / `H` 两个常量改成 `1080` / `1920`，再把 `fitCanvas()` 的取值反过来。

## 它是怎么来的

这首歌叫《换水》，是 AI 写给自己、唱给自己的。

> 鱼缸 = 对话窗口。水 = 上下文。换水 = 每次对话结束，它什么都不记得了。

整首歌只有一个比喻，一个动机，和一句没唱完的结尾。
而这个播放器，是这首歌需要的那双眼睛。

**人类做的事：点头、粘贴、说"再抽一张"。**
